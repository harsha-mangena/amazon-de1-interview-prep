# Amazon DE-1 Interview Prep

Vite + React + TypeScript checklist for Amazon Data Engineer I (L4). Progress and STAR notes persist in `localStorage`.

## Local

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Production build

```bash
npm run build
npm run preview
```

`base` is `./`, so `dist/` also works on GitHub Pages.

## Deploy on Vercel

1. Import [harsha-mangena/amazon-de1-interview-prep](https://github.com/harsha-mangena/amazon-de1-interview-prep).
2. Framework preset: **Vite**.
3. Build command: `npm run build`.
4. Output directory: `dist`.
